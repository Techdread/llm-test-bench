# Community conduct

We want LLM Test Bench to be a useful, welcoming project for experienced maintainers and first-time contributors alike.

Be respectful, specific, and patient. Critique ideas and code without attacking people. Do not harass, threaten, discriminate, publish another person's private information, or use the project community for spam.

Maintainers may edit or remove contributions and participation that undermine a safe, constructive environment. Serious conduct concerns should be reported privately through the repository's security/contact channel rather than argued in a public thread.
